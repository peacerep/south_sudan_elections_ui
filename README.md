# South Sudan elections interface

Review interface for the Perceptions of Peace in South Sudan survey election findings.

The hosted site is a review build and is not yet approved for public release. It includes only browser-safe aggregate data; no respondent-level survey data are stored in this repository.

## Local development

```sh
npm ci
npm run dev
```

The production approval gate remains active. Use `npm run build:draft` to compile the visibly labelled review build.
